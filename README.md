# Bubbling — Abuja nightlife prototype

Mobile-first frontend-only prototype. Open `index.html` or deploy to Vercel.

## Run locally
Open `index.html` in a browser.

## Deploy
[![Deploy with Vercel](https://vercel.com/button)](https://vercel.com/new/clone?repository-url=https://github.com/GraceIkpang/bubbling)

```bash
vercel --prod
```
